# Palmito Labs Logo Assets

Familia de logo basada en la propuesta 3: wordmark mediterráneo, `Palmito` en azul marino, `Labs` en verde agua apagado y abanico segmentado como acento visual.

## Archivos

- `logo-palmito-labs-stacked.svg`: versión apilada, la más cercana a la propuesta 3.
- `logo-palmito-labs-horizontal.svg`: versión horizontal recomendada para cabeceras web.
- `logo-palmito-labs-mark.svg`: símbolo de abanico aislado.
- `logo-palmito-labs-mono-dark.svg`: versión monocroma oscura.
- `logo-palmito-labs-mono-light.svg`: versión monocroma clara para fondos oscuros.
- `favicon.svg`: icono de navegador.
- `logo-preview.html`: hoja visual para revisar la familia completa.
