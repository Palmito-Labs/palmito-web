# Palmito Labs Logo Final

Dirección final basada en la variante A4.3: `Palmito` protagonista, `Labs` debajo, y abanico minimalista muy próximo a la `o` final.

## PNG

- `png/palmito-labs-primary.png`: logo principal apilado.
- `png/palmito-labs-primary@2x.png`: logo principal alta resolución.
- `png/palmito-labs-primary-light.png`: logo principal para fondos oscuros.
- `png/palmito-labs-horizontal.png`: versión horizontal para cabecera web.
- `png/palmito-labs-horizontal@2x.png`: versión horizontal alta resolución.
- `png/palmito-labs-horizontal-light.png`: versión horizontal para fondos oscuros.
- `png/palmito-labs-compact.png`: versión compacta.
- `png/palmito-labs-compact-light.png`: versión compacta para fondos oscuros.
- `png/palmito-labs-isotype.png`: isotipo con fondo crema.
- `png/palmito-labs-isotype-transparent.png`: isotipo transparente.
- `png/palmito-labs-isotype-light.png`: isotipo claro para fondos oscuros.
- `png/favicon.png`: favicon.

## Navegación compacta

`palmito-labs-navigation-dark.svg` y `palmito-labs-navigation-light.svg` reutilizan los elementos raster del logo final en una composición horizontal compacta para la barra vertical y la cabecera móvil. Mantienen el abanico final y el dibujo de las letras; Labs usa tinta oscura o clara para mejorar su lectura. Los PNG originales se conservan intactos.
